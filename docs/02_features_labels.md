## 2. 라벨 `y`

**정의:** 시점 t 에서 본 앞으로 20영업일 실현변동성의 로그.

```
y(t) = log( sqrt( 252 × mean( r(t+1)^2 ... r(t+20)^2 ) ) )
```

r 은 배당 포함 종가 기준 로그 수익률(`{asset}_ret`)이다.

| 규칙 | 이유 |
|---|---|
| t+1 ~ t+20 만 사용 (t 당일 제외) | 당일 수익률은 피처 쪽에 있다. 라벨과 겹치면 누수 |
| 거래 없는 날(수익률 NaN)은 건너뜀 | 휴장일을 0 으로 채우면 변동성이 낮게 나옴 |
| 창 안 관측이 16개 미만이면 NaN | 한국 연휴가 길어도 최소 표본 보장 |
| 패널 마지막 20행은 NaN | 창이 다 차지 않은 라벨은 쓰지 않음 |
| 로그 변환 | 변동성 분포가 오른쪽으로 길어 폭등 구간이 제곱오차를 지배하는 것을 완화. 예측값이 항상 양수가 됨. QLIKE 평가 때는 exp 로 되돌림 |
| 연율화 ×252 | 비교 가능성. 10% 목표 변동성 배분에 그대로 연결 |

**2010년 이후 자산별 평균 (exp 로 되돌린 연율 변동성):**

| 자산 | 평균 y | 연율 변동성 | 라벨 수 |
|---|---|---|---|
| spx | -2.04 | 13.0% | 4,198 |
| tlt | -2.04 | 13.1% | 4,198 |
| gld | -1.94 | 14.3% | 4,198 |
| kospi | -1.88 | 15.3% | 4,124 |
| usdkrw | -2.53 | 7.9% | 4,124 |

전체 평균 -2.09, 표준편차 0.47.

**표본에 대한 주의:** 라벨 창이 20일이라 이웃한 두 행은 19일을 공유한다. 행은 4,000개여도 독립 정보는 자산당 약 200개(2010년 이후 겹치지 않는 20일 창)다. 그래서 평가는 겹침을 고려한 검정(Diebold-Mariano, HAC 분산)을 쓰고 모델은 작게 시작한다.

## 3. 피처 공통 원칙

1. 시점 t 의 피처는 t 까지의 패널 값만 쓴다. 발표 지연은 패널이 이미 반영(FRED·콜금리 1일, OFR 2일, COT 금요일부터)했으므로 여기서는 추가 지연이 없다.
2. 롤링 창은 관측이 창 길이의 80% 미만이면 NaN (`min_periods`).
3. 수준보다 **변화·비율**을 우선한다. 수준만 쓰면 시간 추세를 외우는 모델이 되기 쉽다.
4. 변동성 류는 전부 연율, 로그.
5. 결측은 채우지 않는다. LightGBM 은 NaN 을 그대로 받고, HAR-RV·GARCH 는 수익률 3개만 쓴다.

## 6. 왜 1차와 2차로 나눴나

1. **결측이 시대 표식이 되는 것을 막으려고.** 2차 피처는 2000~2006년 학습 구간에서 비어 있다. LightGBM 이 "HYG 가 비어 있다 = 닷컴 붕괴 시기"로 외울 수 있다. 평가 구간에는 결측이 없으므로 그 규칙은 쓸모없이 학습만 흐린다.
2. **효과를 분리해서 말하려고.** HAR-RV 대 LightGBM(1차)은 "같은 정보로 ML 이 나은가", LightGBM(1차) 대 LightGBM(1차+2차)은 "추가 데이터가 도움이 되는가"에 답한다. 묶음별로 켜고 끄면 기여한 데이터를 특정할 수 있다.
3. **과적합 관리.** 독립 표본이 자산당 약 200개라 피처 58개는 많다. 36개로 기준선을 세운 뒤 22개를 더했을 때 표본 외 성과가 실제로 좋아지는지 확인한다.

최종 모델은 보통 "1차 + 효과가 확인된 2차 일부"가 된다. 부록 후보인 `vix9d_ratio` 는 2차에 있으나 본 실험에서는 제외하고 2013년 이후 구간 비교로만 쓴다.

## 7. 결측 현황 (2010~ 평가 구간)

| 피처 | 결측 | 이유 |
|---|---|---|
| `vol_ratio21` | 20% | 달러원 거래량 없음 (그 자산만 전부 NaN) |
| `vix9d_ratio` | 6% | 2011년 시작 |
| `kr_turnover_ratio` | 5% | 한국 휴장일 |
| 달러원 1차 피처 평균 | 3.3% | 한국 휴장일 수익률 |
| 그 외 1차 피처 | 대부분 1% 미만 | 롤링 창 하한 |

처리 원칙은 다음 단계(평가 틀)에서 규칙으로 구현한다: 라벨이 없는 행만 학습에서 제외, 달러원은 `vol_ratio21` 제외, HAR-RV·GARCH 는 수익률 3개만 사용, 평균·뒤 값으로 채우지 않음.

## 8. 검증 (tests/test_features.py)

- 일정한 수익률에서 라벨이 `0.01 × sqrt(252)` 와 같다.
- 마지막 20행 라벨은 NaN, 휴장 3일은 건너뛰고 계산, 휴장 6일(관측 14개)이면 NaN.
- 롤링 하한: 21일 창에 관측 13개면 NaN.
- 긴 형식 구조와 열 순서가 고정 (`y`, 1차, 2차).
- **look-ahead 없음:** 패널을 t 에서 잘라 다시 만들어도 t 까지의 피처가 같고, 창이 완전한 라벨도 같다. 잘린 뒤 창이 불완전한 라벨은 NaN.

## 9. 알려진 한계

- 라벨이 겹쳐서 행 수보다 유효 표본이 훨씬 적다. 검정과 모델 크기로 대응한다.
- 금의 2000-08~2004-11 구간은 선물 접합이라 고저가 기반 피처(`log_pk21`, `range_pct`)가 NaN 이다.
- 달러원 `adj_close` 는 종가와 같아 환율의 이자 차익(캐리)은 수익률에 없다.
- 2차 피처 중 COT 는 주 1회 값이라 같은 값이 5일 연속 반복된다.
