# 계획 (2026-10-08 ~ 10-19)

## 질문 한 문장
LightGBM 이 HAR-RV·GARCH 보다 앞으로 20영업일 실현 변동성을 더 잘 맞히는가? 그 예측으로 목표 변동성(연 10%) 배분을 하면 고정 비중보다 최대낙폭이 줄어드는가?

## 범위 (줄인 것)
- 자산 5개: S&P 500, KOSPI, 미국 장기채(TLT), 금(GLD), 달러원.
- 문제는 **회귀 하나**: 앞으로 20영업일 실현 변동성(연율) 예측. 분류(레짐 진입 여부)는 회귀 결과를 임계값으로 잘라 부록으로만.
- 모델 2+1: HAR-RV, GARCH(1,1) 기준선 → LightGBM. LSTM 은 하지 않음.
- 평가 지표 2개: 예측은 QLIKE(MSE 보조), 배분은 최대낙폭(샤프·회전율 보조).
- VaR 백테스트(Kupiec 등)는 하지 않음.
- MLOps: MLflow 로 폴드별 run 기록. Airflow(또는 Prefect) 는 핵심 결과 뒤에 일별 DAG 로 감싸기만.
