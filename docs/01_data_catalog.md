# 데이터 카탈로그 (2026-10-11 기준)

`data/processed/daily.csv` — 달력은 S&P 500 거래일, 2000-01-03 ~ 2026-10-09, 6,733행 86열.
재생성: `python pipelines/collect_data.py` (키는 `.env`). 아래 "2010~ 결측"은 평가 구간(2010-01 이후)에서 비어 있는 행의 비율이다.

## 시점 규칙 요약
| 규칙 | 적용 열 |
|---|---|
| 당일 종가 그대로 | 야후 자산·지표, ECOS 금리·거래 자료, VKOSPI, 회의 일정 |
| 1영업일 지연 (익일 공표) | FRED 전부, ECOS 콜금리 |
| 2영업일 지연 | OFR 금융스트레스지수 |
| 보고일(화) +3일 → 금요일부터 | CFTC COT |
| 월별 값을 2개월 뒤부터 | KOSPI 배당수익률 |
| 휴장일 처리 | 수준은 앞값 채움, 수익률·거래량·순매수·거래대금은 NaN. 미국 휴장일 분은 다음 거래일에 합산 |

## 피처 단계 배정
- **1차 (2000년부터 있는 것):** 자산별 실현변동성·수익률·고저범위, 거래량, `vix`, `dxy`, `usdjpy`, `wti`, 미국·한국 금리, `baa10y`, `cp3m`, `ofr_*`, 회의 일정.
- **2차 (늦게 시작):** `vix3m`·`vvix`·`gvz`·`ovx`·`move`, `hyg/ief`, `tips10`, `kr_foreign_netbuy`·회전율, `ewy`, COT, `vkospi`.
- **부록:** `vix9d` (2011~), `hy_oas` (2023~).

## 알려진 한계
- 야후 자료는 과거 수정이 있을 수 있어 완전 재현은 보장되지 않는다. `adj_close` 는 오늘 기준 소급 조정값이라 수준 피처로 쓰면 미래 분배금이 섞인다 (수익률·비율의 변화는 안전).
- FRED·OFR 지연은 일괄 규칙이며 실제 공표 시각은 지표마다 다르다.
- GC=F 접합 구간(2000-08~2004-11)의 금 종가는 선물 정산가라 현물·ETF 와 시점이 다를 수 있다. 금 자체 변동성에는 문제없으나 주식-금 교차 상관 피처에는 쓰지 않는다.
- KOSPI 배당 적립은 2004년부터만 가능하다. 그 이전 `kospi_ret` 은 가격 수익률이다.
